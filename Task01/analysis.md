# Task 1 – Data Design Review

Defects: parallel arrays can become misaligned; char phone[10] cannot hold ten digits plus '\\0'; float cannot represent both systolic and diastolic pressure; fixed text date is hard to validate/sort; count has no bounds check; global state couples functions; sorting age requires synchronized swaps across every array. The repaired model groups related fields in Patient and nests BloodPressure and Date. A pointer lets addPatient update the target record. Structure-of-arrays can be useful for column-wise processing/cache efficiency; array-of-structures makes whole-patient sorting and function passing easier. Sorting remains O(n log n) with an efficient comparison sort; swap movement differs: whole struct versus each parallel field. sizeof and padding are compiler/ABI dependent and should be measured locally.
